# Aanvi API Reference

Base URL: `http://localhost:8000` (or `http://127.0.0.1:8000`)
Interactive OpenAPI Docs: `http://localhost:8000/docs`

---

## Health & System Auditing

### `GET /api/health/components`
Returns the live operational status, latency benchmarks, and mock status of all 14 subsystem nodes.

**Response `200 OK`**:
```json
{
  "system_status": "operational",
  "mock_mode": false,
  "components": [
    {
      "name": "Embeddings",
      "model": "all-MiniLM-L6-v2",
      "status": "ready",
      "mocked": false,
      "latency_ms": 12.4
    },
    {
      "name": "Vector Store",
      "model": "SQLite In-Memory Cosine Vector Store",
      "status": "ready",
      "mocked": false,
      "latency_ms": 4.1
    }
  ],
  "ingested_courses_count": 1,
  "ingested_chunks_count": 48
}
```

## Tutor & Grounded Q&A

### `POST /api/tutor/query`
Executes grounded question answering with multimodal citations.

**Request Body**:
```json
{
  "course_id": 1,
  "user_id": 1,
  "query": "What is the worst-case time complexity of Binary Search?",
  "mode": "scholar",
  "language": "English",
  "allow_outside_knowledge": false
}
```

**Response `200 OK`**:
```json
{
  "answer": "Binary Search has a worst-case time complexity of $O(\\log n)$ because at each step the search space is cut in half.",
  "citations": [
    {
      "source_type": "pdf",
      "document_title": "Algorithms_Lecture_Notes.pdf",
      "page": 142,
      "snippet": "Binary search runs in O(log n) time by halving the search space at each iteration.",
      "open_url": "/api/docs/1/page/142#hl=Binary+search+runs+in+O(log+n)"
    }
  ],
  "is_grounded": true,
  "confidence_score": 0.98,
  "is_safe": true
}
```

## Adaptive Assessment

### `POST /api/assessments/generate`
Generates bloom-aligned, verified quiz items.

### `POST /api/assessments/submit-answer`
Submits student answer, updates BKT mastery state, and returns misconception hints.

## Settings & Theming

### `GET /api/settings/{user_id}`
### `PUT /api/settings/{user_id}`
Updates palette (`"a"` / `"b"`), theme (`"light"` / `"dark"` / `"system"`), sound, and reduced motion.
