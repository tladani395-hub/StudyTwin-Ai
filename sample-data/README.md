# StudyTwin AI — Sample Multimodal Dataset (Track D)

This directory contains pre-processed multimodal course material for instant hackathon evaluation:

1. **`DSA_Textbook.pdf`**:
   - Comprehensive 240-page algorithms textbook covering Divide & Conquer, Binary Search Invariants, Recurrence Relations, and Tree Data Structures.
   - Physical page citation anchors: Pages 140–160.

2. **`Graph_Traversals.pptx`**:
   - 35-slide university lecture deck covering Graph Adjacency representations, BFS queue traversal, and DFS recursion stacks.
   - Slide citation anchors: Slides #12–28.

3. **`DSA_Lecture_04.mp4`**:
   - 35-minute video lecture with Whisper timestamp alignment and audio transcript segmentation.
   - Video timestamp citation anchors: 12:42 (762.0s), 30:20 (1820.0s).
