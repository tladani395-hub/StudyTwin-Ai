## 6. Database as Single Source of Truth & Hard Deletion
- **Rollback on write failure**: `useCourseStore.ts` captures an immutable snapshot before mutations and restores previous state if the backend rejects the write.
- **Stale `localStorage` purging**: `fetchCourses` checks `localStorage.getItem('aanvi_active_course_id')` against active DB records, purging orphaned keys immediately upon reload.
- **Hard Delete vs. Soft Archive**: Added `DELETE /api/courses/{id}/hard` for irreversible cascading removal alongside soft `PATCH /api/courses/{id}/archive`.
- **Permanent Account Erasure**: Added "Permanently Delete My Data" in `frontend/app/settings/page.tsx` with confirmation modal calling `DELETE /api/auth/delete-account`.
